# Scope Summary: Python Hello-World CLI Tool

## Summary
The team is building a minimal Python CLI tool that accepts a name as a command-line argument and prints a greeting. When invoked with a name, it greets that person; when invoked without arguments, it prints a default greeting. The tool has no error handling, flags, or interactive features.

## Agreed Requirements
- Accept name as a single command-line argument (e.g., `./greet Alice`)
- Output format to be confirmed, but proposed as "Hello, <name>!" for named greetings
- When no argument is provided, print "Hello World" (exact punctuation to be confirmed)
- Always exit with code 0
- No interactive prompts
- No command-line flags (no `--help`, `--version`, etc.)
- No error handling or input validation

## Open Questions
- **Exact output format**: Confirm the precise greeting string, including punctuation (comma placement, exclamation mark)
- **Multiple arguments behavior**: What happens if user provides `./greet Alice Bob`? Should it greet only the first argument, concatenate them, or is this unspecified?
- **No-name punctuation**: Should the default be "Hello, World!" (with comma) or "Hello World!" (without comma)?

## Assumptions
- The tool will be invoked as a command-line executable
- Users will primarily use the tool with a single name argument
- "Simple" means minimal code and functionality
- Special characters, empty strings, and whitespace in names will be passed through without validation

## Out of Scope
- Interactive prompt-based input
- Command-line flags of any kind
- Error handling for invalid input
- Input validation or normalization
- Support for looping or multiple greetings per invocation
- Non-zero exit codes for any condition
